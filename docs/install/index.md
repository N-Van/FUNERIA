# Installation

L'espace de travail nécessite des bibliothèques Python de Machine Learning pour
être exécuté. Optionellement, des outils comme `napari` peuvent également être
ajoutés pour visualiser les fichiers `tiff`.

Plusieurs méthodes d'installation sont possibles :

1. [Pixi](./pixi.md)
2. [Pip](./pip.md) (*napari non-installable avec cet outil*)
3. [Conda/Mamba](./conda.md) (*pilote CUDA obligatoire*)
